# YUHACHKA

Коллекция вспомогательных инструментов, главным из которых является WPF-приложение **ColorPickerApp** для подбора и сохранения цветовых схем.

## Возможности
- Поиск по встроенному каталогу цветов `System.Windows.Media.Colors` с фильтрацией по названию или HEX-коду.
- Мгновенный предпросмотр выбранного цвета и читаемый на нём текст (контраст автоматически подбирается).
- Применение цвета в качестве основного фона окна и отображение итогового HEX-кода.
- Список недавно использованных оттенков (до 5 записей) с быстрым выбором.
- Копирование HEX-кода выбранного цвета в буфер обмена одним кликом.
- Переключение светлой и тёмной темы интерфейса.
- Горячие клавиши: `Ctrl+F` — фокус на поле поиска, `Enter` — применить цвет, `Esc` — отменить выбор/очистить поиск.
- Автоматическое сохранение состояния (последний применённый цвет и история) в файле `color-state.json` в папке приложения.

## Требования
- Windows 10/11.
- .NET 6 SDK с поддержкой `net6.0-windows` и WPF.

## Быстрый старт
```bash
# клонировать репозиторий
git clone <repo-url>
cd YUHACHKA

# восстановить пакеты и собрать решение
dotnet restore
dotnet build

# запуск приложения из проекта ColorPickerApp
cd ColorPickerApp
dotnet run
```
> **Примечание:** запуск WPF-приложения возможен только на Windows. В средах без графического интерфейса используйте команду `dotnet build` для проверки сборки.

## Структура проекта
- `ColorPickerApp/` — исходный код приложения на WPF.
  - `ViewModels/` — логика представления и команды.
  - `Models/` — модели данных для цветов и сохранённого состояния.
  - `Services/` — сервисы для чтения/записи состояния.
  - `ThemeManager.cs` — управление темами оформления.
- `index.html` — заготовка для будущего веб-интерфейса.
- `NOTES.md` — служебные заметки о развитии проекта.

## Сохранение состояния
При применении нового цвета информация о нём и список последних оттенков записываются в `color-state.json`. Файл создаётся автоматически и может быть перенесён вместе с приложением, чтобы сохранить персональные настройки.
